# 04 — Train Cohere Transcribe

This step fine-tunes **all weights** of [`CohereLabs/cohere-transcribe-03-2026`](https://huggingface.co/CohereLabs/cohere-transcribe-03-2026) on French audio and transcripts. The model and language are fixed in code.

## Prepare the model and data

The model repository is gated. Accept its access conditions on Hugging Face, then download it on a connected machine. If training runs offline, copy the workspace Hugging Face cache to the cluster.

```bash
export HF_TOKEN=<your-hugging-face-token>
medstt model download CohereLabs/cohere-transcribe-03-2026
```

Provide one or more [AudioFolder datasets](datasets.md) under `<workdir>/datasets/`, each with audio and its transcript. The synthetic TTS dataset and an existing French speech dataset can both be used. Audio must fit in a single model chunk (under 30 seconds).

## Configure training

Edit the `train` section of `<workdir>/medstt.yaml`, generated by `medstt init`:

```yaml
train:
  run_name: cohere-medical
  seed: 42
  data:
    train:
      - path: synth-medical-words
    eval: []
    eval_split: 0.02
    sampling_rate: 16000
    max_label_tokens: 256
  training:
    per_device_train_batch_size: 1
    per_device_eval_batch_size: 1
    gradient_accumulation_steps: 8
    learning_rate: 0.00001
    num_train_epochs: 3
    warmup_steps: 200
    logging_steps: 25
    save_steps: 500
    eval_steps: 500
    save_total_limit: 3
    dataloader_num_workers: 4
```

Set `data.train` to your dataset names or paths. `data.eval` can list separate evaluation datasets; otherwise `eval_split` reserves a fraction of the training data. `max_label_tokens` filters out longer transcripts. `training` accepts options from `transformers.Seq2SeqTrainingArguments`. Full-weight training of this 2B-parameter model needs substantial GPU memory.

## Run and find the output

```bash
medstt train
medstt train --resume  # Continue the latest checkpoint of this run
```

For `run_name: cohere-medical`, the **trained model and processor** are saved in **`<workdir>/runs/cohere-medical/final/`**. This is the directory to load for inference. Intermediate checkpoints are in `<workdir>/runs/cohere-medical/checkpoint-*`; `train_results.json`, `eval_results.json`, and a copy of the `train` settings (`train_config.yaml`) are in the run directory.

The model receives a French decoder prompt. Evaluation generates without the reference transcript and reports WER and CER; when evaluation data is available, the best checkpoint is selected by WER. For multiple GPUs, use the [Slurm script](slurm.md#training). Standalone evaluation remains [TODO](05-evaluate.md).
